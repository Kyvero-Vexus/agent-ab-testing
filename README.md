# agent-ab-testing

OpenClaw skill for designing and running fair A/B tests between two agent conditions.

## What it covers
- defining the variable under test
- controlling invariants
- benchmark design
- harness validation
- serial subagent execution
- objective grading
- blind rubric judging
- pitfalls like ceiling effects, leakage, and harness asymmetry
- iteration and lab-note discipline
